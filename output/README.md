# Output

Analysis outputs generated by the scripts in `../code/` should be written here.

Typical outputs include:

- six-model group-comparison summaries and violin plots
- six-model Age × Group interaction results with FDR correction
- model-quality metrics (MAE, RMSE, mean prediction error, age–BAG slope)
- BrainAge age–BAG regression figures and slope-comparison results
- common-age-range, Cook's-distance, and Huber robust sensitivity results
- main raw/corrected BAG figures
- ROI-wise average-association and interaction summary tables
- within-group ROI correlations and descriptive OLS slopes
- Fisher r-to-z pairwise ROI comparisons
- FDR-corrected ROI results
- NIfTI heatmaps mapped to the FastSurfer DKT+ASEG atlas
- age-bias-corrected workbooks and cross-validation parameter tables

Generated outputs are not tracked by Git by default. The folder itself is retained through this README so that the intended repository structure is clear.
